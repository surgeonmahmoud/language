# دليل مذاكراوي لفهم أنظمة المرحلة الثانوية وإعداد جداول الطلاب

**الرمز الداخلي للمشروع:** `DrZiad` · **العام الدراسي:** 2026/2027 · **الإصدار:** v1.0 · **آخر تحقق للبيانات:** 2026-10-08

مشروع HTML عربي تفاعلي (RTL) للاستخدام الداخلي الحصري داخل فريق **مذاكراوي**، لتدريب دكاترة المتابعة على فهم أنظمة المرحلة الثانوية المصرية وتحويلها إلى قرارات جدولة دقيقة. يعمل **محلياً بالكامل** دون أي خادم أو خدمة خارجية.

> **تنبيه أمني ملزم:** إدخال الرمز `DrZiad` هو آلية تنظيمية للتحكم في العرض المحلي فقط (Client-side UI filter)، وليس وسيلة أمان أو تشفير حقيقية. تأمين البيانات الفعلي يتطلب نظام مصادقة وصلاحيات على خادم مركزي (Server-Side Authentication).

---

## ① الملخص التنفيذي المختصر (النسخة المختصرة)

- **ما هو؟** لوحة تحكم تفاعلية من **20 قسماً** تحوّل حزمة البحث اللوائحي إلى أداة تدريب وعمل لدكتور المتابعة: فهم الأنظمة، فك اختصارات الجداول، تحديد المواد المضافة وغير المضافة، فهم أعمال السنة والتقييمات، تجنّب الأخطاء، التدرّب على الحالات، واجتياز اختبار اعتماد داخلي.
- **خريطة الأنظمة 2026/2027:** الثانوية العامة (ث3 = **320** درجة، 5 مواد مضافة)، البكالوريا المصرية (تراكمي **600** درجة، 4 مسارات، محاولتان)، الثانوية الأزهرية (**650** علمي و**630/590** أدبي، شفهي ملزم)، بجانب الدولي (أمريكي/بريطاني/IB) بالمجموع الاعتباري.
- **القاعدة الحاسمة:** نوع المدرسة ≠ نظام الشهادة. طالب «رسمي لغات» يدرس الثانوية العامة المصرية المترجمة، **ولا** يحصل على أي ميزة تنسيقية، **وله** حق قانوني في تعريب الامتحان.
- **أعمال السنة بالنقل:** 70% (شهر 30% + أسبوعي 15% + كشكول وواجب 15% + سلوك ومواظبة 10%) + امتحان نهائي 30%. إهمالها = رسوب حتمي.
- **المحظورات المطلقة:** الجيولوجيا/الفلسفة بثالثة عام، اعتبار Class Work مادة مستقلة، تطبيق جدول العامة على الأزهري، إهمال القرآن والشفهي، اعتماد جدول دون التحقق من هوية الطالب.
- **النسختان المُسلَّمتان:** (1) نسخة **منفصلة قابلة للتطوير** (ملفات مستقلة)، و(2) نسخة **ملف واحد** `drziad-single.html` سهلة المشاركة.

## ③ الملفات وبنية المشروع

### النسخة الأولى — المنفصلة القابلة للتطوير (مُوصى بها للتعديل)

| الملف | الوظيفة |
|---|---|
| `index.html` | الهيكل العام للوحة التحكم (الرأس، الشريط الجانبي، منطقة المحتوى، البحث). |
| `styles.css` | نظام التصميم: الهوية، الوضع الفاتح/الداكن، RTL، البطاقات والجداول وشارات الثقة، الاستجابة. |
| `print.css` | تنسيق الطباعة (إخفاء التنقل، ترويسة ومصادر الطباعة). |

| `storage.js` | التخزين المحلي (مفاتيح `drziad_`)، التصدير/الاستيراد والتحقق، سجل النشاط. |

| `app.js` | منطق التطبيق: الموجّه (Router)، عرض الصفحات العشرين، الفلاتر، الاختبار، قائمة التحقق، النموذج، الإدارة. |

### النسخة الثانية — الملف الواحد (للمشاركة السريعة)

| الملف | الوظيفة |
|---|---|
| `drziad-single.html` | كل ما سبق مُدمجاً في ملف واحد مستقل. **مُولَّد آلياً**؛ لا تُعدّله يدوياً. |
| `build-single.cjs` | أداة التوليد: تدمج الأنماط والبيانات والمنطق داخل `index.html`. |

## ④ كيفية التشغيل

### النسخة المنفصلة
1. احتفظ بكل الملفات في **المجلد نفسه** (الملفات تُحمَّل بمسارات نسبية).
2. افتح `index.html` في متصفح حديث (Chrome / Edge / Firefox / Safari). يعمل مباشرة من `file://` دون خادم.
3. (اختياري لتجربة أمثل مع الخطوط عبر الإنترنت) شغّل خادماً محلياً: `python3 -m http.server` ثم افتح `http://localhost:8000`.

### النسخة ذات الملف الواحد
- افتح `drziad-single.html` مباشرة بنقرة مزدوجة، أو شاركه كمرفق واحد. يعمل بالكامل دون إنترنت ودون ملفات مصاحبة.

### إعادة توليد الملف الواحد بعد أي تعديل
```bash
node build-single.cjs
```

> **العمل دون إنترنت:** جميع الوظائف الأساسية (التنقل، البحث، التصفية، قائمة التحقق، الاختبار، حفظ التقدم، التصدير/الاستيراد، قراءة المحتوى) تعمل بلا اتصال. خط Google Fonts تحسين تجميلي اختياري مع بديل نظامي عند انقطاع الإنترنت.

## ⑥ منهجية مستويات الثقة (A → E)

| المستوى | الدلالة | الاستخدام |
|---|---|---|
| **A** 🛡️ | مؤكد رسمياً | قانون/قرار وزاري/كتاب دوري بالجريدة أو الوقائع. |

لا يُعتمد على اللون وحده: لكل شارة أيقونة ونص ووصف يظهر عند التمرير مع دعم قارئ الشاشة.

- يُحظر اختراع أي مادة أو درجة أو نسبة، أو تغيير حالة مادة (مضافة ↔ غير مضافة).
- يُحظر الخلط بين: نوع المدرسة ونظام الشهادة · اللغات والدولي · العامة والبكالوريا · العام والأزهري · IGCSE وAmerican وIB.
- حفظ تصنيف الثقة ورموز المصادر (`SRC-…`) وتاريخ التحقق لكل معلومة.
- إبقاء قسم غير المحسوم والتعارضات ظاهراً دون حسم غير موثق، واستخدام «غير متاح» عند غياب المعلومة.
- لا تُعتبر نسبة Class Work ثابتة في كل المدارس، ولا يُعتبر نظام اللغات نظام شهادة منفصلاً، ولا يدل الاسم الإنجليزي على أن الطالب دولي.
- لا تُستخدم بيانات طلاب حقيقية في الحالات التدريبية، ولا تُوضع كلمات مرور أو مفاتيح API أو بيانات حساسة في الكود.

## ⑨ الصيانة والتحديث الدوري

- **مراجعة فورية عند الصدور:** أي قرار يعدّل القرارات 138/2024 أو 234/2025 أو 213/2025، ونشرات مواصفات الورقة الامتحانية.
- **مراجعة سنوية:** الحدود الدنيا للتنسيق، الرسوم الامتحانية، كوتة الشهادات المعادلة، مواعيد دورات IGCSE/EST.
- **وسم المحتوى القديم:** يرتبط كل محتوى بتاريخ `last_verified`؛ وتظهر حالة «تحتاج مراجعة» في لوحة التحكم إذا تجاوز العمر 180 يوماً أو بدأ عام دراسي جديد.
- **المصادر الرسمية:** بوابات وزارة التربية والتعليم، الأزهر الشريف/قطاع المعاهد، والمجلس الأعلى للجامعات.

## ⑩ كيفية تعديل المحتوى (قابلية التوسع)

كل المحتوى في `data.js` داخل كائن `window.DRZIAD_DATA`. بعد أي تعديل، أعد توليد الملف الواحد (`node build-single.cjs`).

- **إضافة مصدر:** أضف عنصراً إلى `DATA.sources` بالحقول `id, kind, authority, title, conf`.
- **إضافة مادة:** أضف عنصراً إلى `DATA.subjects` (حافظ على الحقول البِنيوية؛ استخدم `added: true/false/null`).
- **إضافة حالة تدريبية:** أضف عنصراً إلى `DATA.cases` بالحقول `id, title, available, missing, questions, decision, impact, mistake, conf`.
- **تعديل الاختبار:** عدّل `DATA.examBank` (الأنواع: `mcq`, `tf`, `decision`, `spot`). حد النجاح في `DATA.examPassPercent`.
- **تعديل قائمة التحقق:** عدّل `DATA.checklist` (المجموعة الأولى تُعامَل كبنود **حرجة** لمنع الجاهزية قبل استيفائها).
- **القائمة الجانبية:** تُبنى من `DATA.navigation`.

### التصدير والاستيراد
- من **لوحة الإدارة**: «تصدير كل البيانات» ينتج ملف JSON (مفاتيح `drziad_`). «استيراد نسخة» يتحقق من البنية، يعرض ملخصاً، ويتيح **الدمج** أو **الاستبدال**، ويرفض الملفات غير المتوافقة.
- **نموذج الطالب** يُصدَّر/يُستورد بصيغة JSON مستقلة، مع ملخص قابل للطباعة.

## ⑪ الأمان والخصوصية

- لا تُرسل أي بيانات لأي جهة؛ الحفظ محلي على جهاز المستخدم فقط (LocalStorage بمفاتيح `drziad_`). لا Analytics ولا Trackers ولا Cookies.
- نموذج الطالب يستخدم كوداً اختيارياً بدل الاسم، ولا يطلب الرقم القومي أو العنوان أو الهاتف، مع زر مسح فوري.
- المحتوى المستورد يُعامَل كبيانات: لا تُنفَّذ أكواد من ملفات JSON، وتُدرج النصوص عبر `textContent` لمنع حقن HTML/JS.
- **قسم اختبار الاعتماد** محجوب خلف تأكيد المشرف، و**لوحة الإدارة** خلف رمز العرض `DrZiad` — وكلاهما آلية عرض محلية **وليست حماية أمنية**.

## ⑬ ملاحظة اعتماد

نتيجة اختبار الاعتماد تمثل **«اعتماد داخلي مقترح داخل فريق مذاكراوي»** فقط (حد النجاح المقترح 85%)، وليست اعتماداً رسمياً أو مهنياً. يدعم هذا الدليل قرار الجدولة **ولا يحل محل المستند الرسمي**، والقواعد التعليمية قابلة للتحديث عند صدور قرارات جديدة.
